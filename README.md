# TexTaigaMobile

Android-приложение для учета личных финансов и моделирования бюджета по периодам.

Проект сделан под задачу, где важно не просто записывать доходы и расходы, а сравнивать план с фактом и видеть, как это влияет на будущий баланс.

## Назначение

TexTaigaMobile помогает вести личный бюджет по статьям и периодам:

- задавать статьи доходов, расходов и перемещений;
- планировать суммы по выбранным периодам;
- вносить фактические операции;
- автоматически пересчитывать баланс;
- видеть разницу между планом и фактом;
- выполнять сверку расчетного баланса с реальным остатком;
- выгружать данные в файл для дальнейшего анализа.

Основная логика расчета:

```text
Баланс периода = баланс прошлого периода + доходы - расходы
```

Если по статье и периоду есть факт, в расчете используется факт. Если факта нет, используется план.

## Основные экраны

### Бюджет

Главный экран приложения. Показывает таблицу по периодам:

- статьи доходов;
- статьи расходов;
- перемещения;
- итоговый баланс по каждому периоду.

Плановые значения отображаются отдельно от фактических. Отрицательный баланс выделяется цветом, чтобы было видно возможный кассовый разрыв.

### План

Экран для ввода плановых значений. Пользователь выбирает период и редактирует суммы в таблице по статьям.

Поддерживаются:

- ввод суммы в ячейку;
- комментарий к плановой операции;
- повторение суммы на будущие периоды;
- пересчет итогового баланса после изменения плана.

### Факт

Экран для внесения реальных операций.

В операции указываются:

- период;
- статья;
- сумма;
- тип оплаты;
- комментарий, если он нужен.

Для ввода суммы есть встроенный калькулятор.

### Сверка

Экран сравнения расчетного баланса с реальным остатком.

Пользователь вводит фактическое количество денег, после чего приложение считает разницу. Ее можно:

- исправить вручную через экран факта;
- учесть быстрой корректировкой через отдельную операцию.

### Настройки

В настройках редактируются основные справочники и параметры приложения:

- статьи;
- периоды;
- кошельки и типы оплаты;
- визуальные параметры;
- служебные настройки.

### Выписки

Экран для экспорта данных за выбранный период.

Доступные форматы:

- Excel;
- PDF;
- CSV.

## Технологии

- Java;
- Android SDK;
- Gradle;
- Android View без стороннего UI-фреймворка;
- локальное хранение данных через `SharedPreferences`;
- экспорт PDF через стандартный Android `PdfDocument`.

Минимальная версия Android:

```text
Android 8.0, API 26
```

Целевая версия SDK:

```text
API 35
```

## Структура проекта

```text
app/src/main/java/ru/textayga/mobile/
├── MainActivity.java          # точка входа и навигация между экранами
├── data/                      # сохранение и загрузка данных
├── domain/                    # расчеты, периоды, экспорт, работа с суммами
├── model/                     # модели данных
├── screens/                   # экраны приложения
└── ui/                        # общие UI-компоненты и диалоги
```

Коротко по слоям:

- `model` хранит структуры данных: статьи, планы, факты, периоды;
- `data` отвечает за локальное сохранение;
- `domain` содержит расчет баланса, работу с периодами и экспорт;
- `screens` собирает конкретные экраны приложения;
- `ui` хранит повторяемые элементы интерфейса.

## Запуск проекта

1. Открыть проект в IntelliJ IDEA.
2. Убедиться, что установлен Android SDK и настроен JDK.
3. Дождаться синхронизации Gradle.
4. Запустить конфигурацию `app` на эмуляторе или физическом Android-устройстве.

Если Gradle запускается из консоли:

```powershell
.\gradlew.bat :app:assembleDebug
```

## Сборка APK

Debug-сборка:

```powershell
.\gradlew.bat :app:assembleDebug
```

Release-сборка:

```powershell
.\gradlew.bat :app:assembleRelease
```

Готовые APK появляются в:

```text
app/build/outputs/apk/
```

## Подпись release-сборки

Файл ключа и реальные пароли не хранятся в репозитории.

Для локальной release-сборки нужно создать файл `keystore.properties` в корне проекта по примеру:

```text
keystore.properties.example
```

Пример содержимого:

```properties
storeFile=app/textayga-release.jks
storePassword=change-me
keyAlias=textayga
keyPassword=change-me
```

Сам файл `.jks` также не должен попадать в Git.

## Что не коммитится

В репозиторий не добавляются:

- локальные настройки IDE;
- `local.properties`;
- папки сборки `build`;
- локально скачанные инструменты и SDK;
- APK/AAB-файлы;
- ключи подписи и пароли.

Это настроено в `.gitignore`.
